# Python

Repositório de estudos, exercícios e projetos relacionados à linguagem Python.

O objetivo é centralizar atividades práticas desenvolvidas durante o aprendizado da linguagem, incluindo conteúdos de diferentes períodos que anteriormente estavam distribuídos em dispositivos distintos.

## Conteúdo

- Exercícios de programação em Python
- Fundamentos da linguagem
- Estruturas de controle
- Funções e módulos
- Manipulação de dados
- Automação de tarefas
- Desenvolvimento de aplicações
- Experimentos e projetos práticos

## Objetivo

Centralizar o material prático relacionado ao aprendizado de Python e acompanhar a evolução dos conhecimentos na linguagem.

## Tecnologias

- Python

As versões e bibliotecas utilizadas podem variar conforme a atividade ou projeto.

## Como utilizar

Clone o repositório:

```bash
git clone https://github.com/bispobr/Python.git
cd Python
```

Como o repositório reúne diferentes atividades e projetos, cada diretório pode possuir seus próprios requisitos e instruções de execução.

Quando uma atividade utilizar dependências externas, consulte os arquivos de configuração ou as instruções existentes no respectivo diretório.

## Organização

Os conteúdos são organizados conforme os estudos e projetos adicionados ao repositório. A estrutura pode evoluir à medida que novas atividades forem incorporadas.
